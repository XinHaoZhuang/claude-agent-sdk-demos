# Simple Chat App

一个使用 Claude Agent SDK 构建的聊天应用示例，包含 React 前端和 Express 后端。

![架构图](diagram.png)

## 功能特性

### 多用户支持

**是的，这个 simple-chatapp 示例支持多用户同时访问和对话，并且能够区分不同的用户！**

应用程序具有以下多用户功能：

- **自动用户识别**：每个 WebSocket 连接都会自动分配一个唯一的用户 ID 和用户名（例如 `User-abc12345`）
- **用户区分**：消息会显示发送者的用户名，便于区分不同用户
- **可自定义用户名**：用户可以通过点击用户信息区域（侧边栏底部）的"编辑"按钮来更改显示名称
- **共享聊天会话**：多个用户可以加入同一个聊天，实时查看彼此的消息
- **实时更新**：所有已连接的用户通过 WebSocket 即时接收消息

#### 多用户工作原理

1. 当用户连接时，服务器会自动生成：
   - 唯一的 `userId`（UUID）用于跟踪连接
   - 默认的 `username`（例如 `User-abc12345`）

2. 用户可以自定义用户名：
   - 点击侧边栏中用户名旁边的"编辑"按钮
   - 输入新的用户名
   - 新用户名将显示在所有后续消息中

3. 多个用户可以在同一会话中聊天：
   - 订阅了某个聊天的所有用户都能看到所有参与者的消息
   - 每条消息都显示发送者
   - AI 助手会响应任何用户的消息

#### 技术实现

- **服务器端**：
  - 每个 WebSocket 连接在建立时被分配唯一的用户 ID
  - 消息存储时包含用户信息（userId, username）
  - 支持多个客户端订阅同一个聊天会话

- **客户端**：
  - 显示消息时包含发送者的用户名
  - 提供界面让用户更改自己的用户名
  - 实时接收并显示所有用户的消息

## 快速开始

### 前置要求

- Node.js 18+
- Claude Agent SDK 凭证（设置 `ANTHROPIC_API_KEY` 环境变量）

### 安装

```bash
npm install
```

### 运行

```bash
npm run dev
```

这会启动：
- **后端**（Express + WebSocket）运行在 http://localhost:3001
- **前端**（Vite + React）运行在 http://localhost:5173

在浏览器中打开 http://localhost:5173。

## 生产环境考虑

这是一个演示应用程序。在生产环境中使用时，请考虑：

1. **隔离 Agent SDK** - 将 SDK 移到单独的容器/服务中。这提供了更好的安全隔离，因为 agent 可以访问 Bash、文件系统操作和网络请求等工具。

2. **持久化存储** - 用数据库替换内存中的 `ChatStore`。目前所有聊天记录在服务器重启后都会丢失。

3. **会话同步** - 要在服务器重启后保持 Agent 会话，需要持久化并恢复 SDK 的对话记录。SDK 为多轮对话维护内部状态，必须与存储同步。

4. **身份验证** - 添加适当的用户身份验证和授权。目前，用户识别基于 WebSocket 连接，没有安全的身份验证。在生产环境中：
   - 实现适当的登录/身份验证（OAuth、JWT 等）
   - 将用户 ID 与经过身份验证的账户关联
   - 添加授权检查以控制谁可以访问哪些聊天
   - 将用户信息存储在持久化数据库中
